## 双栈双原生和双 ISP 住宅，区别到底在哪

这是搜索这个词的人最容易买错的地方。丽萨主机在法兰克福有两条完全独立的产品线，配置看起来相似，定位完全不同。

「双栈双原生」这四个字拆开看：双栈指 IPv4 和 IPv6 同时可用；双原生指两种协议的归属地都是德国本地，不是隧道转发，也不是 NAT 共享。判断 IP 到底算不算住宅，看的不是套餐名，而是 ASN 归属和数据库里的 type 字段。商家写「双 ISP 家宽住宅 IP」才代表有住宅属性，只写「原生 IP」的，大概率还是机房段。

这条区别决定了后面所有选择。要住宅属性，价格翻一倍多、没有 IPv6、回程绕路、退款只退余额。要国内访问速度和双栈，就得接受 IP 被识别为机房。

顺带说一句：IP 属性在不同数据库里会有差异，也会随数据库更新变化。买回来建议用 ipinfo、scamalytics、whoer 交叉查一遍，别只信一家的结果。
